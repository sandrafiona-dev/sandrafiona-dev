## What I've Built

### 🫀 OculoCardia AI
A retinal fundus image analysis system that predicts cardiovascular risk from eye scans.

- Segmented retinal vessels using **U-Net** (PyTorch)
- Classified cardiovascular risk using **ResNet-50**
- Built a **FastAPI** backend with Grad-CAM heatmaps for clinical explainability
- Frontend in **React + Vite** with Glassmorphism UI and Framer Motion animations
- Generates clinical **PDF reports** for patients

> The idea: your retina reveals your heart health. Built the whole pipeline from image input to risk report.
